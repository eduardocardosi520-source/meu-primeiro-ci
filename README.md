# Meu primeiro CI

Projeto do [Simulador IoT](https://simulador-iot-eight.vercel.app): circuito, código, placa e produto 3D.

Para abrir e editar: entre no simulador com o GitHub e escolha este repositório em **GitHub → Abrir do GitHub**.

- Peças: P1, R1, R2, P2, P3
- Placa: arduino:avr:uno
- Código: [sketch.ino](firmware/sketch.ino)

`simiot.json` guarda o projeto inteiro; os arquivos em `firmware/` são o código e `cad/` os arquivos STEP originais.
